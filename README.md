# Eduvia

Plataforma de estudos com IA para todo tipo de estudante: o aluno envia seus materiais e a IA gera plano de estudo, sessões, perguntas, revisões espaçadas, jogos, simulados e correção de redação.

Arquitetura, modelo de dados, telas e plano por fases: [docs/ARQUITETURA.md](docs/ARQUITETURA.md).

> Status: fase de planejamento. O código da Fase 1 (MVP) começa após a validação da arquitetura.
